# Multi-Scale Semantic Aggregation Combined with Knowledge Distillation for Efficient Lightweight Remote Sensing Image-Text Retrieval

**Target Journal:** IEEE Geoscience and Remote Sensing Letters (GRSL)

**Status:** Preparing for Submission

## Overview

This repository is the official implementation of our proposed lightweight remote sensing image-text retrieval framework.

The proposed method integrates multi-scale semantic aggregation and knowledge distillation to achieve efficient cross-modal retrieval. Specifically, a lightweight dual-encoder architecture is employed, incorporating Mixture-of-Experts (MoE)-based multi-stage feature fusion and Compact Semantic Region Aggregation (CSRA) to enhance discriminative visual representations. Knowledge distillation and retrieval supervision are jointly employed to improve cross-modal alignment while maintaining a compact model architecture.

The proposed framework is evaluated on two benchmark datasets, RSICD and RSITMD.
